# 🇮🇳 Bharat ResourceNet AI

### AI-Powered Resource Intelligence Platform for India

Bharat ResourceNet AI is an AI-powered resource intelligence platform designed to analyze regional water and food availability across India, identify potential shortages and surpluses, and support data-driven resource allocation.

The platform transforms resource data into actionable insights through interactive dashboards, regional risk analysis, allocation planning, and scenario simulation—contributing to sustainable resource management and informed decision-making.

Developed as part of the **PromptWars × KickToTech 2026 Hackathon**, under the **Environment & Sustainability** track.

---

## 🌍 Problem Statement

India faces challenges in managing and distributing essential resources such as water and food across different regions. Uneven resource availability, changing rainfall patterns, and increasing demand can lead to regional shortages while other areas may have surplus resources.

There is a need for an intelligent platform that can analyze resource availability, identify imbalances, and support better planning and allocation decisions.

## 💡 Our Solution

Bharat ResourceNet AI provides a centralized platform to:

- Monitor regional water and food resource availability.
- Identify areas facing shortages or having potential surplus.
- Analyze resource demand and availability.
- Explore resource transfer and allocation strategies.
- Simulate different scenarios to understand their potential impact.
- Support sustainable and data-driven resource planning.

## ✨ Key Features

### 📊 Interactive Dashboard
Provides an overview of resource availability, regional demand, shortage risks, and surplus resources.

### 🗺️ Regional Resource Map
Visualizes resource availability and risk levels across selected Indian regions.

### 📉 Demand Analysis
Analyzes resource demand against available supply to identify potential imbalances.

### 🚨 Shortage & Surplus Detection
Identifies regions with potential resource shortages and regions with available surplus.

### 🔄 Resource Allocation Planner
Explores possible resource transfers from surplus regions to shortage regions, subject to planning constraints.

### 🧪 Scenario Simulator
Allows users to modify resource conditions and explore potential outcomes under different scenarios.

### 📁 Reports & Data Export
Supports reviewing resource insights and exporting data for further analysis.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install:

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/UtkarshPatil-2025/Bharat-Resource-Net-Ai.git
```

Navigate to the project directory:

```bash
cd Bharat-Resource-Net-Ai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal to view the application.

## 📌 Data & Prototype Disclaimer

The current prototype uses simulated regional resource data for demonstration and testing.

The application is designed to support the integration of official datasets from relevant Indian government sources, including:

- Central Water Commission (CWC)
- India Meteorological Department (IMD)
- Department of Food & Public Distribution
- Ministry of Agriculture

The current prototype should not be considered an official government resource monitoring or allocation system. Its calculations and recommendations are intended for demonstration and planning exploration only.
